# 项目概述

AgentTaskPanel 是一个 macOS 悬浮面板（NSPanel），聚合本机所有 AI Agent（Codex、Claude Code、Cue、Grok Bot、Today、Muse、ChatGPT、Noi）的会话/任务状态，实时显示"哪些在跑、跑到哪了"，任务结束自动通知，点卡片跳回对应 Agent 窗口。

## 解决的问题

并行使用多个 AI Agent 时：

1. 忘记哪个任务还在跑、哪个已经完成
2. 任务完成没有提醒，要挨个窗口切回去看
3. 看到结果想回去继续，找不到对应的会话窗口

## 核心思路

多数 Agent 在本地留有明文/半明文会话文件（Codex 的 JSONL、Claude Code 的 JSONL、Cue 的 sqlite、Grok Bot 的 blob），**文件 mtime 就是天然的活跃度信号**。读这些文件即可还原"哪个任务在跑"，不需要各 Agent 官方支持。

服务端执行的 Agent（Muse、ChatGPT）本地无任务数据，退化为进程检测（"应用在线"），如实标注边界不伪造状态。
