# 开发与发布

## 日常构建（本机使用）

```bash
cd /Users/jascen/Documents/Codex/2026-10-24/w/work/panel

# 1. 构建（build.sh 内含 ad-hoc 签名）
zsh scripts/build.sh

# 2. 停掉正在运行的 App 和数据服务
pkill -f "AgentTaskPanel.app/Contents/MacOS/AgentTaskPanel" 2>/dev/null
pkill -f "AgentTaskPanel.app/Contents/Resources/server.py" 2>/dev/null
sleep 1

# 3. 覆盖安装到 /Applications
ditto AgentTaskPanel.app /Applications/AgentTaskPanel.app

# 4. 重新启动并验证
open /Applications/AgentTaskPanel.app
curl -s http://127.0.0.1:8765/api/tasks | head -c 200
```

构建要求：macOS + Xcode Command Line Tools（swiftc），无需完整 Xcode 工程。

## 发布新版本

```bash
git tag vX.Y.Z
git push origin vX.Y.Z
```

GitHub Actions 自动构建 DMG + SHA256SUMS 并发布 Release。完整流程（含签名细节和常见问题）见项目内 `docs/dev/BUILD-RELEASE.zh-CN.md`。

## 签名说明

- 当前用 ad-hoc 签名（`codesign --sign -`），无 $99/年开发者账号
- ad-hoc 签名解决浏览器下载后 Gatekeeper 判"文件已损坏"的问题；首次打开仍会有"无法验证开发者"提示，右键打开即可
- 买了 Apple 开发者账号后的迁移步骤见 `docs/dev/BUILD-RELEASE.zh-CN.md`

## 修改代码后的验证清单

1. `curl -s http://127.0.0.1:8765/api/tasks` 返回 JSON 且含预期渠道
2. 改动了扫描逻辑：重启 server.py 或重启 App，确认增量缓存没吃掉新逻辑
3. 改动了 panel.html：重启 App（server 无缓存头）
4. 改动了状态推断：构造一个 mtime 在 120s 内/外的会话文件分别验证三态
