# 核心功能

## 多渠道会话扫描（server.py）

| 渠道 | 数据源 | 解析方式 | 结果质量 |
|---|---|---|---|
| Codex | `~/.codex/sessions/**/*.jsonl` | 逐行 JSON，取首条用户消息做标题 | 标题/状态/cwd/deep link 齐全 |
| Claude Code | `~/.claude/projects/**/*.jsonl` | 逐行 JSON，取最近回复 | 标题 + 最近回复 |
| Cue | `~/Library/Application Support/Cue/SessionStore/sessions.sqlite` | protobuf 正则解析 cache_events | 状态/简介/子任务实时文本 |
| Grok Bot | `sand-client-persistence/*.blob` | 自定义二进制格式解析 | 标题/状态 |
| Today | `chat_*.sqlite` | sqlite 直读 | 真实明细 |
| Muse / ChatGPT / Noi | 无本地任务数据 | `pgrep` 进程检测 | 仅"应用在线" |

只看 24 小时内的会话（`SCAN_AGE`），避免面板被历史会话淹没。

## 状态推断

每条任务三个状态：

- **running**：mtime 距今 < 120s（`ACTIVE_WINDOW`）
- **done**：最后一条助手消息时间 ≥ 最后一条用户消息时间
- **idle**：其余情况

## 性能：两级缓存

- **接口级**：`tasks()` 3 秒内直接返回缓存，避免轮询风暴
- **文件级**：`_file_cache` 按 `路径 -> (mtime, 解析结果)` 增量缓存，mtime 未变的文件不重新解析

冷启动约 0.7s，热刷新约 0.01s。

## 标题清洗（clean_title）

会话文件首条消息常是注入内容（AGENTS.md、system-reminder、环境上下文块），`clean_title()` 按前缀黑名单跳过，环境状态块取末尾真实请求，保证面板标题可读。

## 面板交互（panel.html）

- **三态筛选**：点击"执行中 / 已完成 / 空闲"统计卡过滤列表
- **渠道配置**：⚙️ 按钮勾选显示哪些渠道，保存到 `~/.agent-panel-config.json`
- **完成通知**：检测到任务从 running 变 done 时，经 `webkit.messageHandlers.notify` 触发系统通知
- **置顶**：📌 按钮写标志文件，native 侧切换 floating 层级
- **背景三态**：毛玻璃 / 全透明 / 不透明，全透明时红绿灯自动隐藏、鼠标移入浮现
