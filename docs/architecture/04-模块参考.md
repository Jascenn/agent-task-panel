# 模块参考

## src/main.swift（544 行，Swift 外壳）

| 模块 | 职责 |
|---|---|
| `PanelController` (:6) | NSPanel + WKWebView 容器，处理窗口关闭和来自前端的三条消息通道（notify / settings / chrome） |
| `MenuBarManager` (:120) | NSStatusItem 菜单栏图标 + 菜单，10s 轮询刷新执行中数量角标 |
| `ChromeHost` (:229) | 全透明模式下的红绿灯显隐：NSTrackingArea 悬停浮现，离开淡出 |
| `NavDelegate` (:300) | 拦截 `codex://` 等自定义 scheme，交给系统打开对应 Agent |
| `DragView` (:318) | 顶部 40px 拖动区域，hitTest 精细放行按钮区 |
| `PinWatcher` (:335) | 1s 轮询 `~/.agent-panel-pin` 标志文件，切换 NSPanel floating 层级 |
| `startServer()` (:355) | 启动 bundle 内 server.py 子进程 |
| `ServerKeeper` (:373) | 5s 探活 `/api/tasks`，server.py 意外退出自动拉起 |
| `DockMenuDelegate` (:446) | Dock 菜单 + LaunchAgent 开机自启 |

## src/server.py（420 行，数据服务）

| 模块 | 职责 |
|---|---|
| 常量区 (:10-17) | 端口、目录、`ACTIVE_WINDOW=120s`、`SCAN_AGE=24h`、两级缓存 |
| `clean_title()` (:31) | 标题黑名单过滤 + 环境块取尾 |
| `APP_AGENTS` (:57) | 进程名 → (显示名, deep link, 是否有本地明细) 映射 |
| `_cue_str()` (:79) | Cue 自定义二进制文本解码（UTF-16LE / ASCII） |
| `scan_cue()` (:99) / `scan_grok()` (:146) / `scan_apps()` (:176) | 三个 App 型渠道的扫描 |
| `parse_codex_file()` (:227) / `scan_codex()` (:286) | Codex JSONL 解析与扫描 |
| `parse_claude_file()` (:307) / `scan_claude()` (:347) | Claude JSONL 解析与扫描 |
| `tasks()` (:367) | 合并各渠道 → 按 mtime 排序 → 接口级缓存 → 按隐藏渠道过滤 |
| `Handler` (:380) | HTTP 路由：`GET /`（页面）、`GET /api/tasks`、`GET /api/config`、`POST /api/pin`、`POST /api/config` |

## resources/panel.html（357 行，单文件前端）

| 模块 | 职责 |
|---|---|
| `tick()` (:200) | 3s 轮询 `/api/tasks`，驱动全部渲染 |
| `render()` (:230) | 列表渲染 + 三态统计，running→done 变化触发通知 |
| `notifyDone()` (:277) | 经 `webkit.messageHandlers.notify` 发系统通知 |
| `syncPinBtn()` (:284) | 置顶按钮状态与标志文件同步 |
| `applyBg()` (:293) | 背景三态（frost / clear / solid）切换 |
| `loadCfgPanel()` (:317) | 渠道配置面板读写 `/api/config` |

## scripts/build.sh（构建脚本）

swiftc 编译 main.swift → 拷贝 Info.plist / 图标 / panel.html / server.py 进 bundle → `codesign --force --deep --sign -` ad-hoc 签名。产物为仓库根 `AgentTaskPanel.app`。
