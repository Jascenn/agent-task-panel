# 配置说明

## 运行时文件（均在用户主目录）

| 文件 | 用途 | 写入方 |
|---|---|---|
| `~/.agent-panel-config.json` | 渠道隐藏配置，格式 `{"hidden": ["agent-id", ...]}` | panel.html 配置面板 → POST /api/config |
| `~/.agent-panel-pin` | 置顶标志文件（存在即置顶） | POST /api/pin 创建/删除；PinWatcher 轮询读取 |

## 支持的渠道 ID

`codex`、`claude`、`chatgpt`、`grok-bot`、`muse`、`cue`、`today`、`noi`

全部清单由 `ALL_AGENTS`（server.py:60）定义，配置面板即使渠道当前无任务也始终可配置。

## 代码内常量（src/server.py 顶部）

| 常量 | 值 | 含义 |
|---|---|---|
| 端口 | `127.0.0.1:8765` | 数据服务监听地址，仅本地回环 |
| `ACTIVE_WINDOW` | 120 秒 | mtime 距今小于该值视为"执行中" |
| `SCAN_AGE` | 24 小时 | 只扫描 24h 内活跃的会话 |
| 接口缓存 | 3 秒 | `/api/tasks` 在缓存窗口内直接返回 |
| `CODEX_DIR` | `~/.codex/sessions` | Codex 会话目录 |
| `CLAUDE_DIR` | `~/.claude/projects` | Claude Code 会话目录 |

## API 一览

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/` | 返回面板页面（panel.html） |
| GET | `/api/tasks` | 任务列表 + 当前置顶状态 |
| GET | `/api/config` | 全渠道清单 + 当前隐藏配置 |
| POST | `/api/pin` | 切换置顶标志文件 |
| POST | `/api/config` | 保存隐藏渠道列表（body: `{"hidden": [...]}`），保存后立即清缓存生效 |
