三步装上

不需要开发者账号，ad-hoc 签名即可运行

  1. 从 Releases 下载 AgentTaskPanel-v0.3.3.dmg
  2. 把 App 拖进「应用程序」，双击打开
  3. 首次启动允许通知权限；提示「无法验证开发者」时右键 → 打开

升级时直接拖新的进「应用程序」，系统提示就选「替换」。

$
xattr -dr com.apple.quarantine /Applications/AgentTaskPanel.app
被 Gatekeeper 拦住时执行一次即可，比每次右键打开省事。

常见问题

数据会上传吗？

不会。面板只读本机的会话文件，服务跑在 127.0.0.1:8765，没有外发请求。

为什么有些 Agent 只显示「运行中」？

Muse、ChatGPT 的任务在厂商服务端执行，本地没有可读的会话文件，只能确认进程在线。

需要装 Python 吗？

用系统自带的 /usr/bin/python3。如果提示需要安装命令行工具，执行 xcode-select --install。

支持 Windows / Linux 吗？

目前只有 macOS 版本。UI 外壳是原生 Swift，跨平台需要重写窗口层，暂不在计划内。
